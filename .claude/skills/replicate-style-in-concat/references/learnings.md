# Learnings: driving Concat from an agent

Newest first. Each entry says how it was found. Verified = run against the real app (Concat 0.2.8, macOS, debug build, headless MCP).

## 2026-11-03 (last): copying a finished edit from a screen recording, then tuning it with the user

A collaborator re-edited the same take in CapCut while the first version was still being iterated; the user asked for an exact replica built in Concat, then adjusted it by ear and eye. Result: a 9.5 s vertical reel, 3 raw segments, 9 list rows, 9 placed sounds, ~160 steps by one generator, 0 failures. Scripts that came out of it: `analyze-reference-video/scripts/register_frames.py`, `picture_sync.py`, and `replicate-style-in-concat/scripts/add_to_library.py`.

**Reading an edit from a phone screen recording of the editor's preview**
- The recording is the 9:16 preview area inside a taller frame (828x1472 inside 828x1792, top at y=175 here); crop it, then treat it as the reference. Picture cuts: the frame-difference spike on the person region (the instant the list clears is a text end time, not a cut). Text and pill times: count pure-white pixels per frame in each pill's box (a row's pill, icon and label appear on the same frame, with no fade).
- **Its audio lags its picture (0.19 s here), and `align_audio.py` cut times inside a pause are arbitrary.** For lip sync use the picture: `picture_sync.py` warps raw frames with the edit's framing and finds the raw time that best matches each recorded frame; the offset was constant per segment (0.17 to 0.23 s) and the rebuilt poses matched at 4 spot checks. Raw in-point = audio-based offset + that.
- **Framing and grade by closed loop:** `register_frames.py` (SIFT + RANSAC on the static room) gave scale 1.16, rotation about +1 degree (clockwise = Concat's positive `rotation`), offsetY -0.046; render a `preview_frame` with those numbers and register it again (residual under 0.1 degree and 2 px). The edit's grade was a warm shift (blue gain 0.90, red 1.07, luma unchanged, saturation ratio 1.0 once warmed): `concat.white-balance` 5150 K, 6500 is as shot and lower is warmer.
- **Do not take the reference's grade as the goal.** The exact copy looked "very red and bright" to the user; they lowered it themselves (below). Ship the first replica a little cooler and darker than the reference, and say what the reference's grade measured.
- **Text layout:** title lines sit tight (line height 0.78 of the font size; `lineHeight` is a title style key, floor 0.5). Pill and label centres are per element, not on a grid. A label's vertical centre is the same whether it has one line or two. A system font that Concat does not bundle (here Open Sans) is replaced by the closest bundled one (Hanken Grotesk Regular, about 1.22x the size to match the width).
- **Emoji:** `scale` of a PNG padded to a square is its long side as a fraction of the width (0.115 for the reference size). Zero-width-joiner emoji (woman in lotus position, skin tone) do not render through PIL without raqm: draw them with CoreText (a swift `NSAttributedString` in "Apple Color Emoji"), then square-pad.

**Bugs that cost a round**
- **A one-frame black flash at a cut** came from building clips with `MEDIA = 17.6333` while the file's real duration was 17.646 (the audio stream is longer than the video stream: `ffprobe -show_entries format=duration`). Every `clip_trim end` delta was 0.0127 s off, the clips ended up longer than asked, and cut 2 landed at 6.3924 instead of 6.3667. Fix: use the container duration, put every clip start and duration on the frame grid (`n/30`: 3.3667, 6.3667), and check the export with `ffmpeg -vf blackdetect=d=0:pic_th=0.9` (and read `concat.json` clip starts back).
- **Audio filter order is part of the sound.** After the user worked in the window the three clips had three different chains (`denoise, loudness, denoise{}, enhance-voice` / `enhance-voice, loudness, denoise` / `denoise, enhance-voice, loudness`). Loudness before Enhance Voice, or a second Noise Reduction at its default strength, changes the result. The user's ears said the voice was fine, so I did not touch it; read the chains back after the user edits and tell them when the clips differ.

**What the user changed in the window (read back from the saved `concat.json`, project file mtime, not from a screenshot)**
- The first sound (the "Cada día" drop) moved from the instant its row appears (0.383 s) to when the finger touches the row (0.762 s): a sound belongs on the touch, not on the text. The other eight stayed on the row's first frame; a sound under speech is judged by ear, so ask which rows should follow the finger.
- Sound volumes in dB: drop 002 -9.5 dB (0.335), confirmation 001 -15 dB (0.178), confirmation 002 -17 dB (0.141); I had set 0.45 / 0.17 / 0.25. Every sound in the user's videos should sit well under the voice, quieter than I set it first.
- Grade: on top of white-balance 5150 K and exposure -0.3 they added the inspector's Adjust: exposure -0.5, temperature 11000 K (the cool end), on all three clips. Measured on the wall in the same frame (preview_frame, 540x960): red/blue 1.49 (my replica) -> 1.18 (raw footage 1.26), saturation 88 -> 45 (raw 59), frame luma 132 -> 103 (raw 130). So the final look is cooler and less saturated than the raw footage and about 22 % darker than the replica. For this user and this room a neutral-to-cool, slightly dark picture is the target.

**Sound for this kind of reel**
- Concat's own sound shelf is empty (the manifest answers 404; the app says "Sound library coming soon"), so "use the sounds that come with Concat" cannot be done. `add_to_library.py` writes sounds into the user's own library (`<app data>/audio` + `library.json`, the Audio page's Mine shelf, shown after the project is reopened) so they can audition and drag them; 197 sounds were put there and the user chose eight (see `sfx-sources.md`).
- My own synthesized pops (sine sweeps, kalimba, bubble) were rejected ("no me sirven"); the user prefers recorded interface sounds. Dry pops "molestan"; soft variants (low-pass 4.2 kHz + a 35/75 ms echo, normalised to -3 dB peak) were offered but not chosen.
- Matching the reference's sounds by name was not possible (they are CapCut's licensed library). Its tonal "ding" (three pulses on 1.4, 2.8 and 5.4 kHz harmonics) was found from a narrow-band detector in the recording and answered by the closest CC0 sound (Kenney `question_001`), later replaced by the user's own choices. Subtracting my own voice track from the reference's audio failed (the editor's voice processing differs); isolating its effects needs Demucs (`sounds.py`), which costs a download the user must approve.
- Max Enhance Voice (100) + max Noise Reduction (100) + Loudness -16 narrows the pause-to-voice gap (43 dB to 26 dB measured) and still got "la voz perfecta" from the user: the user's ear beat the metric again.


## 2026-11-03 (later): a list that builds up beside the speaker (one raw take, no edited reference)

An 11 s vertical reel: one take, three rounds of three rows (frequency pill, emoji, hand-written label), each row entering on the word the speaker says. Built by `gen_steps.py`-style generator in the scratchpad, 157 steps, 0 failures, export -16.2 LUFS.

- **Verified:** `clip_transform` with `offsetX` moves a *title* clip sideways (the `title_add` tool itself only takes `offsetY`). A `\n` in a title's `content` makes two lines. A title `background` with `backgroundPaddingX/Y/Radius` makes a white pill.
- **Verified:** a font installed on the Mac but not bundled (Bodoni 72) renders by `fontFamily` name in the preview and the export; it would fall back on another machine, because the project does not carry it.
- **Gotcha:** `title_add above: true` takes the first free lane above everything over its span, **including lanes you minted for icons**. Images added to those lanes afterwards were pushed to other times (an icon at 2.67 s landed at 4.37 s). Give every kind of overlay its own lanes and pass `trackId` explicitly to `title_add`; mint all lanes first.
- **Gotcha:** `export_start` returns `job`, not `createdId` (`$exp.job` in `mcp_run.py`). `timeline_read` needs `project_open` first in a fresh session. The local ffmpeg has no `drawtext`.
- **Transcription trap:** whisper `base` on a quiet, low-rumble track invented "Acá es esto cada día..." over the first 4 s, where the spectrogram showed no voice at all. Always check the spectrogram or per-100 ms energy before believing a transcript's times, then transcribe each voiced burst alone.
- **Light:** white text over a bright ceiling failed 3:1 contrast on 91 % of the title zone (reference reel: 8 %); `concat.exposure` at -0.7 EV brought it to an estimated 42 %. Measure contrast per zone before choosing text colour.
- **Voice clean-up (measured, not heard):** the noise in this take was mostly a low rumble, nearly as loud as the voice. Concat has no high-pass or EQ; `concat.denoise` and `concat.enhance-voice` remove hiss (above 2 kHz, about 20 dB) but the rumble only 3 to 4 dB. What worked: an ffmpeg copy of the file with `highpass=f=100` twice plus `afftdn=nr=18:nf=-45:tn=1` (video stream copied, rotation kept, `-map 0:v:0 -map 0:a:0` to drop the data tracks), then `denoise 60` + `enhance-voice 40` + `loudness -16` in Concat. Pause level against speech went from -12 dB (raw) and -17 dB (first export) to -32 dB. Stacking more is not better: `denoise 60` + `enhance-voice 80` measured worse than `enhance-voice 40` alone on the same pauses.
- **Echo and "far away" voice (a distant phone recording): the user's ear beat my measurements.** Enhance Voice / afftdn / denoise dulled the highs by 4 to 5 dB against the mids and did nothing for the room. What helped: WPE dereverberation (`nara_wpe`, single channel, taps 10, delay 3, 3 iterations, STFT 1536/384 at 48 kHz, via `uv run` with `nara_wpe numpy scipy`), then a presence EQ (`equalizer` +3 dB at 3 kHz, +2 dB at 6.5 kHz; Concat's own `treble`/`bright` changed nothing measurable). The user could not tell WPE strengths apart, so the gentlest is used.
- **Concat's audio filters are level-dependent.** The same chain gave a pause 44 dB under the voice on the quiet original and only 23 dB under it on a copy that WPE had normalised 15 dB louder: its denoiser did not gate noise at the higher input level. Feed Concat a file at the original level (rescale WPE's output to the input's RMS) and do the ffmpeg clean-up (high-pass, `afftdn`) before WPE, not after. Final chain: ffmpeg `highpass 140` x2 + `afftdn nr=18`, WPE at original level, presence EQ, then Concat `denoise 60` + `enhance-voice 40` + `loudness -16`.
- **Noise here was a motor hum:** tonal peaks at 68 Hz and its harmonics (136, 204, 272 Hz) in the pauses; a plain 100 Hz high-pass leaves the 136 Hz one. Find tones with an FFT of a pause before guessing filters (`numpy`, 0.5 Hz bins, prominence over the +-60 Hz median).
- **How to measure it:** compare a pause against a nearby spoken word with `volumedetect` on the same file, in windows with no placed effect (a pop or swish inside the window made the export look 20 dB noisier); repeat on two pauses, one window alone swung by 8 dB.
- **Gotcha:** `mcp_run.py` step names (`as`) must not contain dots: `$mx1_5.05.createdId` is read as name plus path.
- **Legibility without a plate:** a dark outline (`strokeWidth` 0.0025, `strokeColor`) on white text plus -1.0 EV on the footage read well over the chair and the sunlit floor; 0.004 made the serif title blobby.
- **A "silent start" can be a laugh:** the first 1.2 s after a cut at a transcript's start were a laugh and a smile, with voice-like energy (4.1 to 4.4 s) that the energy detector counted as the first phrase. The mouth, in crops of the face every 0.1 s, settled it: the phrase began 1.1 s later.
- **Gesture sync:** a 4-frame strip around each spoken word showed the pattern "up / right at mid height / right and low" for day / week / month in all three rounds; the finger lands 0 to 0.2 s after the voice starts, so rows enter 0.1 s after the word.

## 2026-11-03: identifying sounds and transitions in a reference

Tested on `replica_v3` (64 s, voice + CC0 music bed + 46 effects placed by hand, so the truth is known). Scripts: `transitions.py`, `sounds.py` in `analyze-reference-video`.

- **Transitions: TransNet V2 works.** Every one of 15 cards' end times found as a cut within 0.02 s; the 11 sliding entrances came out as gradual transitions. Its cut time is the *next* frame after the model's output index (`(i + 1) / fps`), verified against the known card times.
- **Sounds: YAMNet on the mixed track does not work.** It sees the voice and the music, not the effects (recall about 7 %, AUC at chance). With Demucs removing the voice the "when" improves a lot, the "what" does not: only long whooshes get recognised; pops, ticks and light swishes are not recognisable by AudioSet classes at all.
- **Honest numbers** (they moved when I computed precision per threshold instead of only recall): at the 20 dB floor of `analyze.py report`, 36 of 46 effects found (chance 23 %, p95 46 %), 42 of 45 events real. An earlier "91 % found, 20 of 76 unmatched" belonged to the 15 dB cut and to a different count of events. Always report found, precision and the shifted-at-random baseline together.
- **The YAMNet "Whoosh" score is tiny even for real whooshes** (max 0.11). A ranking test (AUC 0.90 on crops cut at known effect times) made it look usable, but a fixed threshold only catches about a third. Do not claim effect names from it.
- **Cost:** Demucs through `uv run --with demucs` is 32 packages, a 138 MB PyTorch wheel and 84 MB of weights; 70 s of stereo audio took 28 s on an M-series CPU. The first end-to-end run of `sounds.py` was 93 s including everything.
- **Not tried:** CLAP / PANNs for naming effects (CLAP is 615-776 MB); a reference with effects someone has listened to and annotated. The measurements above are all against my own effects at low volume.

## 2026-10-23 (third): a 5-minute raw take of one person, no reference video

- **Raw shape:** one fixed shot, 301.9 s, 44 spoken takes for about 21 lines (each line 2 to 5 times), a CapCut end card in the last 2 s. Finished edit: 64.5 s from 21 chosen takes, 25 clips.
- **Whisper word timestamps drift on long files** (several seconds, many words on one time). Energy-based phrase detection plus a per-phrase transcript fixed it: `phrases.py`.
- **The old per-take loop is replaced by `takes_to_plan.py`**: describe the edit by what is said and let anchors place everything; 0 manual timestamps.
- **Verified in the app:** keyframes on `scale`, `opacity` and `offsetY` work through `keyframe_set`; `clip_update` with `filters: [{"id": "concat.loudness", "params": {"target": -16}}]` normalises a clip (export measured -16.1 LUFS); `clip_update` with `fadeIn`/`fadeOut`/`volume` shapes the music; `clip_transform` places and scales an overlay icon; `title_add` with `fontFamily` "Montserrat" and "DM Serif Display" renders in those fonts; a title `background` with `backgroundPaddingX/Y/Radius` makes a label chip.
- **Gotcha:** `tracking` is not a small em fraction: 0.06 spread the letters of a chip across three lines. Leave it at 0 (or well under 0.02).
- **Gotcha:** two title clips on the same screen position for 0.6 s looked like one garbled title. The typed title of the next line must start after the previous one ends; shorten `dur`.
- **Gotcha:** an overlay icon placed at the face height (`offsetY` -0.10) covers the speaker; keep icons in the top band (-0.28 to -0.30) or just above the caption (+0.17).
- **Music:** a 43 MB CC0 ambient piece at gain 0.10; the export's LRA fell to 2 LU and the integrated loudness stayed -16.1. See `sfx-sources.md`.

## 2026-10-23 (later): natural starts and sound effects

- **Complaint:** some clips opened on her looking away or not ready to speak. The replica was frame-identical to the reference at every cut, so the cause was the reference's cut points, which sit inside pauses (measured lead-in before the voice: mean 0.20 s, up to 0.95 s; six segments under 0.04 s, which clips the first syllable). Fix: `tighten_segments.py` (see `analyze-reference-video`).
- **Effects:** two CC0 sets (see `sfx-sources.md`), a palette with `make_sfx_pack.py`, 21 effects placed with `build_steps.py --sfx` on two audio lanes. 201 steps, 0 failures. The raw swishes (0.07-0.2 s) had to be slowed and echoed to work as a slide.
- **Verified:** a lane created with `track_add bottom: true` gets a lowercase id (`t4`); use the returned `createdId`, not a guessed `T5`.
- **Verified:** correlating a noisy effect against the final mix, and the swell detector, both failed to find effects mixed under speech (they are really there: an isolated project with one effect shows it at the right second). Do not use those checks for effects under a voice.

## 2026-10-23: first real pair (a 4-minute talking-head recording and its 57-second vertical reel)

- **What the pair was:** the raw file was one continuous take of a person talking (plus a trailing editor end card); the edit was jump cuts of that take with B-roll, app screenshots and image cards laid over the continuing voice, phrase-by-phrase captions, and a few typed titles. The B-roll was **not** in the raw file, so the replica rebuilds the voice track and the captions exactly and puts labelled placeholders where the other footage goes.
- **Result of the run (verified):** 24 aligned voice segments, 14 placeholders, 70 captions, 3 titles, all built by one 154-step `mcp_run.py` session with 0 failures; export 1080x1920 at 30 fps, 1702 frames = the reference's duration. `compare.py` found 19 of 25 reference cuts, with timing error median 0 and worst 0.13 s. The misses were cuts between adjacent placeholders of the same colour (give neighbours different colours if cut detection matters) and a picture-only cut inside one take.
- **Picture alignment failed on a talking head** (17 of 26 shots `low`, wrong sources), **audio alignment worked** (scores 0.76-0.92, boundaries to about 10 ms). Added `align_audio.py`; see `analyze-reference-video`.
- **The SFX detector fired on the voice** (251 events on a voice-only track, strongest ones were phrase starts after digital silence). Added `in_speech` / `after_silence` flags, a strength floor and a `sfx_verdict`. Real finding for that reel: no music bed, no placed sound effects; the sound design was the voice only.
- **Whisper `base` (ggml, Spanish)** gave usable word timings but wrong words for names and jargon. Correct against the burned-in captions of the reference; keep a list of guesses for the user to review.
- **Caption style that matched the reference:** `captions_add` with `offsetY 0.28` (lower third), `style {color: "#F4EFD0", fontWeight: 600, fontSize: 0.034, strokeWidth: 0, shadow: true}`; typed titles at `offsetY -0.28`, weight 800, size 0.045. Concat has no typewriter animation, so typed titles are static text.
- **Correction:** `title_add` with `above: true` is the right way to get a title over the footage (the schema says it takes the first free lane above everything occupied over the span). The earlier note that it "did not move the title to a visible lane" was a misreading: the title it created without `above` landed on `T1`, behind the footage.
- **Verified:** `concat --project <folder>` opens a project directly in the window; the folder must not be open in another process.
- **Verified:** media imported through the headless MCP has no bin thumbnails until the window opens the project; the window logs missing `.thumb.jpg` files once and creates them.
- **Not available / not done:** icons (a check mark, a bookmark) and small picture-in-picture overlays were left out; a text typing animation; the reference's picture-only cuts.

## 2026-10-23: first session, synthetic footage

- **Verified:** the whole path works end to end: `project_create` -> `media_import` -> `clip_add` / `clip_trim` / `clips_move` -> `clip_update` (volume, fadeOut, transitionIn) -> `title_add` -> `project_save` -> `preview_frame` -> `export_start` / `export_wait`. A 3 s 640x360 export finished in seconds.
- **Verified:** the source in/out recipe in `SKILL.md` gives exact `sourceStart`, `start`, `duration`.
- **Verified gotcha:** a title that `title_add` puts on `T1` is hidden behind footage on `T2`; the same style on `T4` shows. Higher lane number draws above. `above: true` fixes it (see the later entry). Always check the `track` and a `preview_frame`.
- **Verified gotcha:** `preview_frame` `output` and `export_start` `output` must be under the home folder; elsewhere the call is refused with "is outside where this API writes".
- **Verified:** `media_import` can read files from anywhere (even `/private/tmp`); only writes are restricted.
- **Verified:** the tool list has 42 tools in 0.2.8 (the docs/agent notes say 45; trust `--list-tools`).
- **Verified:** Concat's sound library manifest (`https://raw.githubusercontent.com/concatapp/assets/main/audio/manifest.json`) returns 404, so there is no built-in SFX to place. User-supplied files or `make_sfx.py` stand-ins are needed.
- **Detector behaviour (synthetic):** cuts found within 0.04 s; high-pass noise swells found as `whoosh_swell` with the peak about 0.13 s before a cut that the generator had at 0.10 s; a 55 Hz decaying sine impact is found only by the low-band detector (the percussive stem drops it); a 120 BPM tick gave 117.5 BPM.
- **Alignment (synthetic):** flat-colour footage cannot be localized within a repeated colour (low confidence is expected there); real footage with texture should do far better. Untested on real footage yet.
- **Not yet tried:** speed ramps, masks, keyframed transforms, captions_add, multiple timelines, ducking via `keyframe_set` volume, `edit_apply` batches, the window (non-headless) mode, import of vertical footage with a different project size.
